[BUG] [alpha] monacoManager acquireEditor LRU branch is unreachable

Summary: The pool-full LRU reuse block filters !inUse after a prior !inUse search has already failed, making that branch unreachable.

Source references:
- cortex-ide/src/utils/monacoManager.ts:720
- cortex-ide/src/utils/monacoManager.ts:766

Deterministic proof:
Path condition to reach LRU branch:
1) available = find(!inUse) is falsy  -> all pool entries are inUse
2) pool is full                         -> enters branch starting at line 766
3) leastUsed = filter(!inUse)[0]        -> empty by condition (1)
4) leastUsed is always undefined        -> branch never executes

Conclusion: 'reuse least recently used editor' block is unreachable dead code.

Expected:
LRU branch should select a reusable editor when pool is full.

Actual:
LRU candidate is always empty under current path conditions.
